The Cocoa, WinForms and Textual backends now use platformdirs to provide app-specific paths. As a result, some locations have changed: on macOS, `app.paths.config` has moved from `~/Library/Preferences/<app id>` to `~/Library/Application Support/<app id>`; on Windows, `app.paths.config` and `app.paths.data` are now both `%LOCALAPPDATA%\<author>\<formal name>`, without the previous `Config` and `Data` subfolders. The Windows AppData location is now obtained from the Known Folders API, so setting the `LOCALAPPDATA` environment variable no longer alters app paths. Toga does not move any existing files; an app that needs to preserve files stored at an old location can migrate them at startup with a snippet like:

```python
import shutil
from pathlib import Path

# The old location for your platform; this example is macOS config.
old_config = Path.home() / f"Library/Preferences/{app.app_id}"
if old_config.exists():
    shutil.copytree(old_config, app.paths.config, dirs_exist_ok=True)
    shutil.rmtree(old_config)
```
